## Running a demo

Every demo is self-contained. Open its folder and follow the README there. Most are small web projects:

```sh
cd <demo-folder>
npm install
npm run dev
```

These are experiments and prototypes, built quickly and in the open. Expect rough edges. Ideas and feedback are welcome through issues.
